💾 Step 2: Install Punjabi/Hindi Voices

🖥️ Windows 10/11:

  1. Open Settings → Time & Language → Speech
  2. Click "Manage voices"
  3. Click "Add voices"
  4. Search for and install:
    • Hindi (India) - Heera, Swara
    • Urdu (Pakistan) - Salman
    • Punjabi (India) - if available
  5. Restart your browser after installation

Alternative Windows Method:

  1. Go to Settings → Apps → Optional Features
  2. Click "Add an optional feature"
  3. Search for "Speech" or "Text-to-speech"
  4. Install Hindi/Urdu speech packages

🍎 macOS:

  1. Open System Preferences → Accessibility → Spoken Content
  2. Click "System Voice" dropdown
  3. Click "Customize..."
  4. Download:
    • Lekha (Hindi)
    • Sangeeta (Hindi)
  5. Restart your browser

🐧 Linux:

  1. Install eSpeak with Hindi support:
    sudo apt-get install espeak espeak-data-hi
  2. Or install Festival with Hindi:
    sudo apt-get install festival festvox-hi-nsk
