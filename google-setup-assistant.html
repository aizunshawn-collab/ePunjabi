🎯 Google Cloud TTS Setup Assistant

1 Create Google Cloud Account

Sign up for Google Cloud and get $300 free credit for new users!

🌐 Open Google Cloud Console

2 Create New Project

Create a project specifically for your Punjabi voice translation app.

  1. Click "Select a project" → "New Project"
  2. Project name: Punjabi-Voice-Translation
  3. Click "Create"

3 Enable Text-to-Speech API

Enable the Cloud Text-to-Speech API for your project.

  1. Go to "APIs & Services" → "Library"
  2. Search for "Cloud Text-to-Speech API"
  3. Click on it and press "Enable"
🔌 Enable API

4 Create API Key

Generate an API key to authenticate your requests.

  1. Go to "APIs & Services" → "Credentials"
  2. Click "+ Create Credentials" → "API Key"
  3. Copy your API key (starts with AIza...)
  4. Click "Restrict Key" → Select "Cloud Text-to-Speech API"
🔑 Create API Key
