🔐 Step 2: Enable Microphone Permissions

🌐 For Chrome:

  1. Look for the 🎤 microphone icon in the address bar (left side)
  2. Click on it and select "Allow"
  3. OR go to chrome://settings/content/microphone
  4. Make sure this site is allowed

🔷 For Edge:

  1. Look for the 🎤 microphone icon in the address bar
  2. Click on it and select "Allow"
  3. OR go to edge://settings/content/microphone
  4. Add this site to allowed list
